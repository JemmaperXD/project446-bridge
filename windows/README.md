# Project 446 — запуск на Windows

Эта папка нужна для одной вещи: **чтобы игра подключалась к игровому
координатору Project 446, даже если провайдер режет соединение с ним.**

Мост поднимается только для `gc.project446.com` — это не VPN и не прокси для
всего интернета. TLS остаётся сквозным: мост не расшифровывает трафик игры.

Внутри уже лежит всё нужное, **Python устанавливать не надо** — он в папке
`python`.

---

## Что нужно

- Windows 10 или 11
- Steam и установленная игра **CS:GO Legacy (Project 446)**
- Больше ничего.

---

## Шаг 1. Распаковать архив

1. Нажмите на архив правой кнопкой → **«Извлечь всё…»**.
2. Выберите папку, например `C:\Project446`.
3. **Важно:** играть нужно из распакованной папки. Запуск прямо из ZIP
   не сработает.

Должно получиться так:

```
C:\Project446\
    start_bridge.bat
    1_SETUP.bat
    2_CHECK_UPDATES.bat
    3_UNINSTALL.bat
    bridge.py
    README.md
    python\
```

---

## Шаг 2. Один раз запустить `1_SETUP.bat`

1. Откройте папку `C:\Project446`.
2. Двойной клик по **`1_SETUP.bat`**.
3. Windows спросит разрешение (окно **UAC**) — нажмите **«Да»**.
4. Появится чёрное окно с надписью «Готово» — нажмите любую клавишу.

Этот шаг нужен **один раз**. Он добавляет в системный файл `hosts` строку
`127.0.0.1 gc.project446.com`, чтобы игра шла через мост. Рядом сохраняется
резервная копия `hosts.project446.bak`.

Если запись уже добавлялась старой версией и приклеилась к предыдущей строке
(например, `127.0.0.1 localhost127.0.0.1 gc.project446.com`) — просто запустите
`1_SETUP.bat` ещё раз: он аккуратно разделит строки и запишет всё правильно.

---

## Шаг 3. Прописать запуск в Steam

1. Откройте **Steam**.
2. Библиотека → правой кнопкой по **CS:GO Legacy (Project 446)** → **Свойства**.
3. Вкладка **«Общие»** → поле **«Параметры запуска»**.
4. Вставьте туда ровно это (одной строкой):

```
"C:\Project446\start_bridge.bat" %command% -secure -novid
```

> `-secure` включает защищённый режим, `-novid` пропускает вступительное
> видео. Оба флага должны идти **после** `%command%`.

> Если распаковали в другую папку — замените `C:\Project446` на свою.
> Кавычки вокруг пути обязательны.

5. Закройте окно свойств.

---

## Шаг 4. Играть

Нажмите **«Играть»** в Steam. Дальше всё само:

- откроется чёрное окно «Project 446»;
- появится «Запускаю мост…» и «Мост работает»;
- затем запустится игра.

Чёрное окно закрывать не надо — пусть висит позади игры. Если мост уже
запущен (например, вы перезапускаете игру), скрипт переиспользует его.

---

## Как обновить мост

При запуске игры `start_bridge.bat` сам проверяет GitHub (не чаще раза в
сутки) и, если вышла новая версия, пишет об этом в чёрном окне. Ничего
автоматически не скачивается и не устанавливается.

Проверить вручную можно в любой момент — запустите **`2_CHECK_UPDATES.bat`**.

Если есть новая версия:

1. Скачайте новый `Project446-Windows.zip` со страницы
   [releases](https://github.com/JemmaperXD/project446-bridge/releases/latest).
2. Закройте игру и чёрное окно моста.
3. Распакуйте архив **в ту же папку** (`C:\Project446`) с заменой файлов.
4. Параметры запуска в Steam менять не нужно — они остаются прежними.

Запись в `hosts` при обновлении сохраняется, повторно запускать
`1_SETUP.bat` не нужно (только если в описании релиза прямо сказано иначе).

---

## Как проверить, что мост работает

1. В чёрном окне должно быть написано **«Мост работает.»**
2. Рядом со скриптом появится файл **`bridge.log`** — в нём видно, как идут
   соединения (`входящее соединение`, `туннель через …`, `пул: живых …`).
3. Можно вручную: `Win + R` → `cmd` → Enter → вставить:

```
netstat -ano | findstr 127.0.0.1:443
```

Должна быть строка со словом **LISTENING**.

---

## Если что-то не работает

**«Мост не поднялся за 16 секунд»**
- Порт 443 занят другой программой (веб-сервер, старый экземпляр моста).
  Закройте её или перезагрузите компьютер.
- Антивирус блокирует `python\pythonw.exe` — добавьте папку в исключения.
- Посмотрите `bridge.log` — там будет причина.

**Игра запускается, но к серверу не подключается**
- Убедитесь, что `1_SETUP.bat` был запущен и в hosts есть отдельная строка
  `127.0.0.1 gc.project446.com` (файл
  `C:\Windows\System32\drivers\etc\hosts`, открывается Блокнотом от
  администратора). Если строка склеена с предыдущей — запустите
  `1_SETUP.bat` заново, он исправит.
- Проверьте, что в параметрах запуска Steam путь правильный и в кавычках.

**Windows SmartScreen: «Windows защитила ваш компьютер»**
- Нажмите **«Подробнее»** → **«Выполнить в любом случае»**. Это обычный
  Python, просто без цифровой подписи.

**Firewall спрашивает про python**
- Нажмите **«Разрешить доступ»**.

**Мост долго ищет прокси**
- Первый запуск занимает до минуты: мост скачивает список публичных
  прокси и проверяет их. Дальше рабочий пул сохраняется в
  `good_proxies.json` и старт быстрый.

## Как всё убрать

Самый простой способ — запустить **`3_UNINSTALL.bat`**:

1. Двойной клик по `3_UNINSTALL.bat`.
2. Windows спросит разрешение (UAC) — нажмите **«Да»**.
3. Подтвердите удаление.
4. На вопрос «Удалить папку с мостом?» ответьте `Y`, если мост больше не
   нужен.

Скрипт уберёт из `hosts` только нашу запись `127.0.0.1 gc.project446.com`
(и её старые «склеенные» варианты), при желании удалит папку с программой.
**Игру, Steam и сохранения он не трогает.**

После удаления не забудьте убрать параметры запуска в Steam:
Библиотека → CS:GO Legacy → Свойства → Параметры запуска — удалить строку,
где есть `start_bridge.bat`.

Если хотите убрать всё вручную:

1. Уберите строку из параметров запуска Steam.
2. Удалите строку `127.0.0.1 gc.project446.com` из
   `C:\Windows\System32\drivers\etc\hosts` (или восстановите
   `hosts.project446.bak`).
3. Удалите папку `C:\Project446`.

## Что внутри

| Файл | Зачем |
|---|---|
| `start_bridge.bat` | запускает мост и игру (его указываем в Steam) |
| `1_SETUP.bat` | один раз добавляет (или исправляет) запись в hosts |
| `2_CHECK_UPDATES.bat` | проверяет, нет ли новой версии моста |
| `3_UNINSTALL.bat` | убирает запись из hosts и (по желанию) папку с мостом |
| `fix_hosts.ps1` | вспомогательный скрипт для `1_SETUP.bat` |
| `remove_hosts.ps1` | вспомогательный скрипт для `3_UNINSTALL.bat` |
| `check_updates.ps1` | вспомогательный скрипт для проверки обновлений |
| `bridge.py` | сам мост |
| `python\` | готовый Python, ставить ничего не нужно |
| `bridge.log` | появляется после запуска, лог работы |
| `good_proxies.json` | появляется после запуска, рабочий пул прокси |
| `update_check.txt` | появляется после проверки, кэш на 24 часа |
