# Project 446 bridge

Локальный TCP-мост до игрового координатора **Project 446**
(`gc.project446.com`), если провайдер не даёт подключиться к нему напрямую.

```
игра  ──►  127.0.0.1:443  ──►  [мост]  ──►  публичный HTTP-CONNECT-прокси  ──►  213.152.43.203:443
                                    TLS end-to-end, без расшифровки
```

Мост не трогает остальной трафик, не является VPN и не лезет в игру. Наружу
уходит только то, что игра и так отправляет на `gc.project446.com`.

## Что делает

- слушает `127.0.0.1:443` и проксирует TCP-соединения до
  `gc.project446.com:443`;
- сам находит и постоянно проверяет публичные HTTP-CONNECT-прокси;
- **проверяет сертификат** при проверке прокси, поэтому прокси с подменой
  TLS (корпоративные SSL-инспекторы вроде Zscaler) в пул не попадают —
  игра всегда получает настоящий сертификат Project 446;
- использует один «залипший» прокси первым, чтобы внешний IP не менялся на
  каждом соединении (это важно для reservation cookie на бэкенде);
- уводит мёртвые прокси в карантин, сохраняет рабочий пул в
  `good_proxies.json`, переживает обрыв и перезапуск;
- пишет лог в `bridge.log` (с ротацией).

## Установка на Windows

Скачайте `Project446-Windows.zip` из
[releases](https://github.com/JemmaperXD/project446-bridge/releases) —
внутри уже лежит Python, ставить ничего не нужно.

1. Распакуйте в `C:\Project446`.
2. Один раз запустите `1_SETUP.bat` (добавит `127.0.0.1 gc.project446.com`
   в `hosts`).
3. В Steam → Свойства игры → Параметры запуска:

   ```
   "C:\Project446\start_bridge.bat" %command% -secure -novid
   ```

   `-secure` — защищённый режим, `-novid` — без вступительного видео.
   Флаги должны идти после `%command%`.

4. Нажмите «Играть».

Обновление: `2_CHECK_UPDATES.bat` (плюс автоматическая проверка при запуске
игры). Удаление: `3_UNINSTALL.bat` — уберёт запись из `hosts` и по желанию
папку, игру и Steam не тронет.

Подробности — в [`windows/README.md`](windows/README.md).

## Установка на Linux

Нужен Python 3.9+ и права root (порт 443 и запись в `/etc/hosts`).

**systemd** (Debian, Ubuntu, Fedora, Arch и т.д.):

```sh
sudo ./linux/systemd/install.sh
```

**OpenRC** (Alpine, Gentoo, Artix):

```sh
sudo ./linux/openrc/install.sh
```

Скрипты ставят мост в `/opt/project446-bridge`, состояние — в
`/var/lib/project446-bridge`, добавляют запись в `/etc/hosts` (с бэкапом
`/etc/hosts.project446.bak`) и включают автозапуск.

```sh
# логи
journalctl -u project446-bridge -f          # systemd
tail -f /var/lib/project446-bridge/bridge.log

# остановить / удалить
sudo systemctl stop project446-bridge
sudo ./linux/systemd/uninstall.sh --purge
```

В Steam → Свойства игры → Параметры запуска рекомендуется:

```
%command% -secure -novid
```

`-secure` — защищённый режим, `-novid` — без вступительного видео.

## Ручной запуск (любая ОС)

```sh
python3 bridge.py            # слушает 127.0.0.1:443
python3 bridge.py 8443       # другой порт (тогда правьте hosts)
```

Не забудьте направить `gc.project446.com` на `127.0.0.1` в hosts.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BRIDGE_LISTEN_HOST` | `127.0.0.1` | адрес локального listener'а |
| `BRIDGE_LISTEN_PORT` | `443` | порт (аргумент командной строки важнее) |
| `BRIDGE_TARGET_IP` | `213.152.43.203` | IP координатора |
| `BRIDGE_TARGET_PORT` | `443` | порт координатора |
| `BRIDGE_TARGET_SNI` | `gc.project446.com` | SNI и имя для проверки сертификата |
| `BRIDGE_STATE_DIR` | папка со скриптом | где хранить `bridge.log` и `good_proxies.json` |
| `BRIDGE_STICKY_FIRST` | `1` | сначала пробовать один и тот же прокси |
| `BRIDGE_CONSOLE` | `auto` | вывод в stdout: `auto` — только в терминале, `0` — выключить, `1` — всегда |

## Требования

- Python 3.9+ (только стандартная библиотека, зависимостей нет)
- исходящий доступ к публичным HTTP-прокси (порт 80/443/8080/…)
- права на прослушивание порта 443 (root / `CAP_NET_BIND_SERVICE`)

## Как это работает

1. При старте мост занимает порт, загружает сохранённый пул и проверяет его.
2. Проверка прокси: TCP → `CONNECT` → TLS-хендшейк с проверкой сертификата
   `gc.project446.com`. Прокси, подменяющий сертификат, отбрасывается.
3. На входящее соединение выбирается прокси: сначала «залипший», иначе гонка
   нескольких кандидатов, кто быстрее ответит `200`.
4. Байты переливаются как есть (TCP relay), TLS не трогается.
5. В фоне пул обновляется каждые 60 секунд, а список кандидатов — по мере
   расхода (но не чаще раза в минуту).

## Ограничения

- Публичные прокси бесплатны и нестабильны: возможны задержки и обрывы,
  мост переподключается автоматически.
- Внешний IP будет IP-адресом прокси, а не вашим. Для игрового трафика это
  не важно, но учитывайте при диагностике.
- Проект не связан с Valve или Project 446; используйте на свой риск.
